### 已处理的本机故障与后续播放流程

- 抓取发生异常后，淘汰浏览器实例；原生组件异常只在同一总期限内用新实例重试一次。解析器也不再回收失败的导航实例供下一个源使用。
- 初轮日志出现过 Windows `CO_E_NOTINITIALIZED`。新增平台线程上的 STA 状态检查与缺失时恢复保护，已用原生测试验证连续十次初始化／释放、无引用累积和拒绝改变已存在的 MTA。实际连续复测的恢复计数为 0，不能据此声称已定位所有第三方组件故障。
- 平台要求依据：[CoGetApartmentType](https://learn.microsoft.com/en-us/windows/win32/api/combaseapi/nf-combaseapi-cogetapartmenttype)、[CoInitializeEx](https://learn.microsoft.com/en-us/windows/win32/api/combaseapi/nf-combaseapi-coinitializeex)。
- 播放器内候选、重新解析与同源换线失败后，可尝试最多两个其他已高置信匹配的源；只按唯一集标识继续，并保留实际进度，不按列表下标猜集。
- 下一集预解析延迟到稳定播放五秒后，单任务去重；暂停、缓冲、后台和恢复时取消。诊断保留阶段、耗时与恢复结果并脱敏，播放器样式保持原样。

## mgnacg 站点专用适配

正常播放流程与通用 MacCMS 不同：`static/js/player.js` 特意跳过 encrypt=2 的通用 Base64 解码，按 `playerconfig.js` 的 `from` 选择公开解析器，`static/player/parse.js` 把原始数据传到 iframe。仅解码 MacCMS 字段无法得到媒体地址。

已加入 `MgnacgAdapter`，限定 HTTPS 的 `www.mgnacg.com/bangumi/` 页面：

1. 读取正常播放页的 `from` 与原始 URL 字段，按站点配置选择 cloudplay、yp2、yp3 或 ccxl；未知线路保留通用浏览器发现路径，不猜测接口。
2. 请求正常公开解析页，从 viewport / charset 两个动态 meta ID 按站点公开 `setting.js` 协议派生 AES-CBC 密钥与 IV，再解码 `config.url`。不运行远程 JavaScript，不处理登录或验证码。
3. 只接受 HTTP(S) 的实际媒体类型 URL；空值、网页、脚本、破损密文均拒绝。正常 cloudplay 页声明 referrer=never，因此候选不强加源站 Referer；具体媒体仍经过现有验证和原生实播。

调查中公开解析器两次成功返回 HTTP 页面，但解码结果均为空（带源站 Referer 重试也为空）。这是正常响应未提供媒体的证据，不能宣称解码能力本身修复了远端资源。未取得真实流时，Referer 策略也尚未得到实际播放验证。

解码测试使用 Node crypto 独立生成的已知向量，另有 HTTP 集成测试验证正常跳转参数、原始字段保留、头部策略及严格站点范围。适配器、MacCMS、解析器与规则加载合计 60 项测试通过，静态分析通过。Windows 实播报告位于 `dist/playback-audit/mgnacg-adapter/`。

专用适配后的 Windows 复测：《鬼灭之刃 柱训练篇》《葬送的芙莉莲》各两线路均在解析阶段超时，未得到实际媒体候选，没有首帧证据。HTTP 调查证明能够解码正常公开解析响应，但现网抽样仍未提供可播流；不能将单元测试通过称为新增源可用。临时候选已移出 assets，保留实验规则，默认源列表仍为原有五个。

Windows 原生实播已验证《鬼灭之刃 剧场版 无限城篇第一章 猗窝座再来》线路1：1920×1080、首帧约5.8秒、连续实际进度超过10秒、拖动通过、无错误事件。本次媒体来自 `bfikuncdn.com`，与已有稀饭样本的 `play.xfvod.pro` / `dl.playxf.top` 不同；域名不同不能保证底层提供商完全独立。

后续覆盖检查：《咒术回战第三季》第12集、《海贼王》第1180集均为站点当前列表的首集项；各自线路1起播失败，而线路2都取得 `bfikuncdn.com` 媒体，1920×1080、持续实际进度与拖动均通过。规则使用本项目扩展 `preferredLineIds: ["road:1"]`，默认优先已验证的第二线路，保持原线路 ID 与备用线路；电影样本只有一条线路时自动保留原线路。并非把所有作品的第一线路删除，也不按列表下标猜跨线集数。

默认首选复测使用 `-MaxLines 1`，确认《咒术回战第三季》第12集直接从线路2解析、持续播放与拖动均通过。

限制：《葬送的芙莉莲》公开播放页列出的 CDN 请求明确返回 HTTP 403 / `The region has been denied`，原生批量测试中该作品搜索亦曾超时；不能保证该源所有作品、线路及网络均可用。未尝试改变地区或绕过访问限制。

其他初筛：mutefun 当前搜索返回403，暂不加入；LMM 正常 API 可搜索、可列集，但其 vxdev 正常公开解析请求仅返回 `pir`，无媒体地址，暂不深入适配。baimao 搜索可返回作品但本轮未完成实播，nekodm 仅返回跳转页，两者均未加入默认列表。不会将仅搜索正常的候选标为可播放。

脱敏实播报告：`dist/playback-audit/new-mxdm/`、`mxdm-coverage/`、`mxdm-preferred/`（默认首选线路复测）。规则加载和映射测试15项通过，静态分析无问题。仅验证 Windows 与当前网络，尚无 Android 真机或整集稳定性证据。

## 作品线路偏好与明确失效恢复

- 成功线路按作品目录源、作品 ID、作品类型和视频源严格隔离，本地保存最多100条，30天过期。成功证据要求播放器具有渲染信号、当前候选收到有效视频参数，且播放中实际进度连续推进5秒；暂停、后台、缓冲和拖动会打断累计。Controller 的首帧 future 可能复用，因此该信号不是每个候选独立的首帧测量，也不会单独触发记忆。
- 详情页将记忆线路优先列出；线路不存在时保留站点原顺序。每个选集按钮、历史继续观看仍先使用明确指定的线路，偏好不会把用户点选的线路偷偷替换。自动下一集沿当前实际播放线路继续。
- 初次详情解析明确未找到地址时，可尝试同源的其他线路；仅在 episodeKey 唯一且一致时换线，不按集数下标猜测。取消、网络故障与超时不走此快速换线分支。
- 媒体探测在全部请求头变体均明确返回403/404/410或非媒体内容后丢弃该候选；有其他正常候选时仍继续。503、慢响应、探测超时保留原有可播放回退，避免把慢源直接判死。
- 播放器收到明确 HTTP403/404/410，或解析明确为空时，候选耗尽后跳过对同一线路的重复解析，继续安全换线。只有错误文本明确带HTTP状态语义才识别，URL路径中的数字不算。403仅标注拒绝访问，不一律声称地区限制或防盗链；不对整个源永久封禁。

业务回归验证涵盖存储隔离/过期/容量、拖动和暂停中断、同集换线/取消/歧义、明确HTTP失效候选、暂时503回退及播放器直接换线。此轮不新增源、不修改播放器布局，亦未新增 Android 真机实播证据。
