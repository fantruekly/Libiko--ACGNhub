## 1. 概述

### 1.1 设计目标

全 App 视觉重设计，覆盖外壳布局、四个模块（动漫/漫画/轻小说/游戏）、播放器、阅读器。采用 Infuse / Apple TV 风格的简洁轻量设计语言。

### 1.2 参考风格

- Infuse（Figma / iOS）：毛玻璃导航、大封面、极简 UI chrome
- Apple TV：深色沉浸播放、大间距、仅必要元素

### 1.3 核心原则

- **简洁轻量**：最小化 UI chrome，内容优先
- **竖向滚动**：全局竖向滚动，无横向滚动行（播放器内剧集列表除外）
- **单一强调色**：`#007AFF` 仅用于选中态和主 CTA，其余用中性色
- **左侧竖列导航**：四模块 + 设置，可收起

## 3. 排版系统

| 角色 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| 模块标题 | 28px | 1.3 | 600 | 每个模块首页顶部标题 |
| 区域标题 | 20px | 1.4 | 590 | "热门推荐"等分类标题 |
| 作品标题 | 15px | 1.45 | 510 | 卡片内作品名（最多2行） |
| 正文 | 14px | 1.6 | 400 | 简介、列表文字 |
| 辅助文字 | 12px | 1.5 | 400 | 来源名、日期、标签 |
| 侧边栏标签 | 11px | 1.5 | 510 | 导航文字，letter-spacing 0.02em |

字体栈：
- 正文/UI：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 轻小说正文：`serif, "Songti SC", "Noto Serif CJK SC", "SimSun", serif`
- 播放器内：`system-ui, -apple-system, sans-serif`

CJK 规则：
- 所有标题行高 ≥ 1.3
- 正文行高 1.7–1.8
- 无负 letter-spacing（CJK 在固定 em 网格上）

## 4. 外壳布局

### 4.1 整体结构

```
┌──────┬─────────────────────────────────────────────────────┐
│  侧  │  顶部栏（模块标题 + 搜索 + 头像）   48px             │
│  边  ├─────────────────────────────────────────────────────┤
│  栏  │                                                     │
│ 72px │              主内容区（竖向滚动）                    │
│      │                                                     │
└──────┴─────────────────────────────────────────────────────┘
```

### 4.2 侧边栏

**展开状态（默认）：**
- 宽度 72px
- 5 个项（垂直排列）：动漫、漫画、轻小说、游戏、设置（底部）
- 每项：24px 图标（SVG，1.6px 描边，currentColor）+ 下方 11px 文字
- 选中态：图标 `--accent` + 文字加粗 + 左侧 3px 竖线指示器（`--accent`）
- 未选中：图标 `--muted` + 文字 regular
- Hover：背景 `--sidebar-active`
- 顶部收起按钮（☰ 图标，24px，muted 色）
- 设置项上方有分割线（`--border`）
- 背景：`--sidebar-bg`

**收起状态：**
- 点击 ☰ → 侧边栏向左滑出（300ms cubic-bezier(0.4, 0, 0.2, 1)）
- 左侧出现 12px 宽竖条（`--border` 色），上有 ▶ 箭头图标（16px，accent 色）
- Hover 竖条 → 背景 `--sidebar-active`
- 点击 ▶ → 侧边栏从左侧滑入恢复
- 收起后滚轮在竖条上可切换模块
- 快捷键 Ctrl+1~4 切换模块
- 收起/展开状态持久化到本地设置

### 4.3 顶部栏

- 高度 48px
- 左侧 72px + 16px 留白后，展示当前模块名称（28px semi-bold）
- 右侧：搜索图标按钮 + 头像/设置入口
- 点击搜索 → 搜索栏展开替代标题（动画过渡）
- 背景：`--surface`，底部 0.5px `--border` 分割线

## 5. 动漫模块

### 5.1 动漫首页

**布局：**
- Hero 精选卡片（高 240px，全宽）→ Pill 按钮组 → 作品网格（竖向滚动）

**Hero 卡片：**
- 全宽封面图 + 底部 80px 渐变遮罩（透明→黑 0.6）
- 遮罩上叠加作品标题（24px bold 白色）、来源·年份·评分
- "立即观看"按钮（accent 色填充，白色文字）
- 每 8 秒自动切换，手动左右箭头切换
- 点击进入详情

**Pill 按钮组：**
- `[继续观看] [热门推荐] [最近更新]`
- 并排胶囊按钮，左对齐，间距 8px
- 选中：accent 色填充 + 白色文字
- 未选中：透明底 + muted 色文字 + `--border` 边框
- 默认选中「热门推荐」

**作品网格：**
- Grid 自适应列数（卡片固定 150px 宽），间距 16px
- 每张卡片：150×200 封面（圆角 10px）+ 标题（最多2行）+ 来源标签
- Hover：封面 scale 1.02 + 阴影加深，0.2s ease
- 触底懒加载

**「继续观看」视图：**
- 从本地历史取最近 10 条，按时间倒序
- 空态："还没有观看记录，去发现好番吧" + 搜索入口

**「最近更新」视图：**
- 按源更新日期排序

### 5.2 动漫搜索页

**布局：**
- 顶部返回箭头 + 搜索输入框（占据剩余宽度）
- 源筛选 Chips 行
- 结果网格

**搜索输入框：**
- 圆角 10px，背景 `--bg`，16px 字号
- 左侧搜索图标，右侧清除按钮（有内容时显示）
- 300ms 防抖自动搜索

**源筛选 Chips：**
- 水平排列，可横向滚动
- 默认选中「全部源」

**状态管理：**
- 空态（未输入）："输入关键词搜索动漫" + 搜索图标 48px
- 加载态：骨架屏（闪烁灰色矩形）
- 错误态：错误信息 + "重试"文字按钮
- 无结果态："未找到「关键词」相关动漫" + "换个关键词试试"

### 5.3 动漫详情页

**布局：**
- 封面大图（16:9，全宽）→ 标题区 → 标签 → 简介 → 剧集列表 → 底部按钮

**封面大图：**
- 16:9 比例，全内容区宽度，无圆角
- 底部 40px 蓝紫色渐变遮罩（模块色），自然过渡到下方内容

**标题区：**
- 作品名 28px bold
- 来源 · 年份 · 评分 ★8.5

**标签 Chips：**
- 小号圆角胶囊，背景 `--sidebar-active`，文字 11px `--accent`，间距 6px

**简介：**
- 最大 4 行，超出显示 "... [展开]" 文字按钮

**剧集列表：**
- Card 容器（`--surface`，圆角 12px）
- 每行 48px：集号 + 标题 + ▶ chevron
- 行间 0.5px `--border`
- 右上角排序切换（正序/倒序）
- 点击进入播放器

**底部按钮：**
- 页面底部固定，accent 色填充，白色文字
- 高 48px，圆角 12px，左右 margin 16px
- "播放最新"（仅一个 primary CTA）

**顶部栏：**
- 返回 + 收藏（心形，选中填红）+ 分享

## 6. 漫画模块

### 6.1 与动漫模块的差异

| 维度 | 动漫 | 漫画 |
|---|---|---|
| Pill 按钮 | 继续观看 / 热门推荐 / 最近更新 | 继续阅读 / 热门推荐 / 最近更新 |
| 封面比例 | 150×200 (3:4) | 150×212 (≈1:1.414) |
| 结果角标 | 无 | "更新至第 X 话" |
| 模块色 | 蓝（仅装饰） | 暖橙 `#FF9500`（仅装饰） |
| 章节 | 剧集列表 | 话数列表 |

### 6.2 漫画详情页

**额外元素：**
- 顶部栏："登录此源"按钮（需登录的源才显示，accent 色文字按钮）
- 底部按钮：
  - "从第 1 话开始阅读"（primary，accent 色填充）
  - "继续阅读第 XX 话"（有历史时显示，secondary：透明底 + accent 色边框 + accent 色文字）
- 源信息卡片（`--bg` 背景）：
  - 可直接获取：仅显示"本内容来自「XXX 漫画源」"
  - 需登录：显示源名称 + "前往登录"按钮（accent 色文字按钮）

## 9. 播放器与阅读器

### 9.1 动漫播放器

**进入时：** 隐藏侧边栏，全屏 `#000000`

**顶部栏：** 半透明黑底 `rgba(0,0,0,0.6)`，左返回 + 右剧集标题，3s 无操作自动隐藏

**视频区：** 16:9 居中，适配窗口

**底部控制栏（3s 无操作自动隐藏）：**
- 进度条：2px，已播放 accent 色，缓冲灰色，可拖拽
- 控制按钮：后退 10s / 播放暂停（40px accent 色）/ 前进 10s
- 右侧：倍速（循环切换 0.5→0.75→1.0→1.25→1.5→2.0）、分辨率下拉、全屏、设置

**控制栏背景：** 渐变遮罩 `rgba(0,0,0,0.8)` → 透明

**剧集列表：** 底部横向滚动条（播放器内唯一横向区域），当前集 accent 高亮

**快捷键：**
- 左键视频 = 播放/暂停
- 右键 = 切换控制栏
- Space = 播放/暂停
- ← → = 后退/前进 5s
- F = 全屏
- Esc = 退出全屏/返回

### 9.2 漫画阅读器

**环境：** 保留侧边栏，浅色背景

**阅读模式（默认）：** 竖向连续滚动

**顶部栏：** 返回 + 当前话标题 + 下一话快捷按钮 + 设置齿轮

**内容区：** 垂直排列漫画页图片，自适应宽度居中

**手势：**
- 滚轮 = 竖向滚动
- 点击图片 = 全屏（单页 + 左右键翻页）
- 双指捏合 = 缩放

**底部浮动条：** 页面指示器（竖向滚动模式下参考）

**设置面板（齿轮弹出）：**
- 阅读方向：竖向滚动 / 横向翻页（左→右）/ 横向翻页（右→左）
- 缩放模式：适应宽度 / 适应高度 / 原始大小
- 背景色：白 / 灰 / 黑

**预加载：** 前后各 3 页

**进度保存：** 自动保存到本地历史

### 9.3 轻小说阅读器

**环境：** 保留侧边栏，浅色背景

**文字区：** 最大宽度 680px 居中（约 40-45 中文字符/行）

**排版参数：**
- 字号：默认 16px，可调 12–24px
- 行高：默认 1.8
- 段落间距：16px
- 字体：serif（宋体/Noto Serif CJK）

**顶部栏：** 返回 + 章节标题 + 目录按钮 ☰ + 字号设置 Aa

**目录面板（右侧滑入，280px）：**
- 树形目录（卷→章）
- 当前章节高亮
- 点击跳转

**字号设置面板（底部 Sheet）：**
- 字号滑块（12–24px，带实时预览）
- 行距：紧凑(1.5) / 标准(1.8) / 宽松(2.2)
- 主题：日间（白底黑字）/ 护眼（米黄底）/ 夜间（黑底灰字）

**底部：** 上一章 / 下一章导航

**进度保存：** 实时保存所在章节

## 10. 通用交互规范

### 10.1 按钮样式

| 类型 | 背景 | 边框 | 文字 | 用途 |
|---|---|---|---|---|
| Primary | `--accent` | 无 | 白色 | 主要 CTA（每个页面仅一个） |
| Secondary | 透明 | 1.5px `--accent` | `--accent` | 次要操作（如"继续阅读"） |
| Text | 透明 | 无 | `--accent` | 文字链接（如"前往登录"、"重试"） |
| Ghost | 透明 | 无 | `--fg` | 导航、返回、设置图标按钮 |
| Pill | 选中：`--accent`；未选中：透明 | 未选中：1px `--border` | 选中：白；未选中：`--muted` | 分类切换 |

所有按钮 hover 时 background 亮度 ±0.06（OKLch L 通道），0.15s 过渡。文本对比度在 hover 后不降低。

### 10.2 模块装饰色

每个模块有一个装饰色，仅用于详情页封面渐变遮罩和 Hero 卡片的细微点缀：

| 模块 | 装饰色 | Hex |
|---|---|---|
| 动漫 | 蓝紫 | `#5856D6` |
| 漫画 | 暖橙 | `#FF9500` |
| 轻小说 | 青绿 | `#34C759` |
| 游戏 | 紫红 | `#AF52DE` |

装饰色不出现在任何交互状态或功能按钮上，上限为每个模块详情页 1 处使用。

### 10.3 动画

- 页面切换：200ms fade + 100ms slide (8px)
- 侧边栏收起/展开：300ms cubic-bezier(0.4, 0, 0.2, 1)
- 搜索栏展开/收起：250ms ease-out
- 卡片 hover：0.2s ease scale 1.02 + shadow
- 按钮 hover：背景色过渡 0.15s

### 10.4 状态反馈

- 按钮 click：scale 0.97 → 0.15s spring
- 收藏切换：心形填红/空心，0.2s ease
- 加载：骨架屏（闪烁灰色矩形），非 spinner
- 错误：居中错误信息 + "重试"按钮
- 空态：图标 + 引导文字 + 行动入口

### 10.5 可访问性

- 所有可交互元素 ≥ 44px 触摸目标
- focus-visible：2px accent 色外框，offset 2px
- 对比度：正文 ≥ 4.5:1，大文字 ≥ 3:1

| 模块 | 页面 | 空态文案 |
|---|---|---|
